- The users should see the home screen when they open the site.

- On the home page, the user will see an empty state page, and be prompted to either login or register

- On the registration page, the user will have to enter their name, surname, cell number, email and a password.
  - After clicking the Register button, the input will be validated and it is valid, the user's account will be registered.
    - A success message will be issued, and the user will be directed to the login page
  - If the input is not valid, an appropriate message will be issued, and the user will be prompted to register again

- On the login page, the user will have to input their email and password to login
  - If the user clicks the login button and the login is successful, a success message will be displayed and the user will be redirected to the Home page
  - If the login is unsuccessful, an appropriate message will be displayed with the next steps for the user

- Once the user clicks on the "New List" button, they will be redirected to the creation screen, with input fields for the list details.
  - When the user saves the details, they will be redirected to the Home page

- The user will have the option to search for a list using a name.
- The user will have the option to sort the lists using the date created or category.

- When the user clicks on a shopping list, they will be directed to the shopping list page, where the items associated with that list will be displayed
  - A button for deleting the current list will also be available to the user
  - In this page, a back button will be present, and upon being clicked, it will return the user to the home page
  - Another button for adding items to the list, and upon being clicked, it will direct the user to the item creation page.
  - Upon clicking on a shopping list item, the user will be directed to the list item details page

- The user will be able to navigate to teh Profile Page from the navigation menu
