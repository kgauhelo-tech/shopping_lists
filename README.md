### Shopping List Project

# Purpose

A shopping list application using ReactTS and json-server that allows users to create and track different shopping lists using Redux for state management. Use of proper web app navigation practices.

# Functionality

- Authentication
  - Login
  - Register - Email, Password, Name, SUrname, Cell number
  - Profile - View, Update, Update login credentials
  - Encryption for protection

- CRUD Functions
  - Adding a shopping lists with - name, quantity, optional notes, category, images and adding shopping list items
  - Reading all shoppings lists - viewing details about each list
  - Updating shopping lists and items
  - Deleting existing shopping lists and shopping items
  - Searching for items by name, and updating the URL to include the query
    - Update the page based on the URL
  - Sorting through list items according to name, category, date added
    - Display sorting on the url, and update search based on URL
  - Allow users to share their shopping lists with others

- Data management:
  - Store items in a JSON server
  - User Redux to manage state
  - Optimize for smooth performance
  - Protect user data and privacy

- Responsiveness:
- Use 320px, 480px, 768px and 1024px as breakpoints

- Can extend the functionality if needed
